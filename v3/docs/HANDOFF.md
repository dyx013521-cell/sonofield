# SonoField v3 · TASK-001 交接说明

当前阶段只开发双 EBAZ4205 的时间同步。工程器件固定为 `xc7z010clg400-1`，主板 N18/X5 输入 50MHz，约束周期20ns；全部自动化入口为 PowerShell 7。

## 本地使用

在仓库根目录打开 PowerShell 7：

```powershell
$PSVersionTable.PSVersion
./v3/simulation/run_xsim.ps1
./v3/vivado/run_task001.ps1
```

第二条仅运行 RTL 仿真；第三条按仿真、综合、实现、时序分析顺序运行两个独立工程。默认工具路径为 `D:\amd2025_2\2025.2\Vivado\bin`，其他电脑通过 `-VivadoBin` 指定。不要用 Windows PowerShell 5 执行这些入口。

项目文件位于 `v3/vivado/build/ebaz_master/ebaz_master.xpr` 与 `v3/vivado/build/ebaz_slave/ebaz_slave.xpr`；布局布线后的设计保存在各自 `v3/evidence/task001/ebaz_*/routed.dcp`。构建使用 Tcl 内存流程，GUI 审查布局和时序应打开 routed.dcp；`.xpr` 保存源码与约束，不应把 GUI 中未运行的 synth_1/impl_1 状态误认为批处理没有执行。换电脑可从入口重建。

## 设计交接

- Master 转发50MHz给 Slave，Slave 时间戳使用转发时钟；Slave 自身 N18 晶振只负责失钟检测。
- 144bit 帧包括 HEADER、BOARD_ID、CMD、32bit序列号、64bit时间戳与 CRC16。下降沿发送，上升沿采样，VALID 回低后才提交完整帧。
- 解码延迟146周期；上锁前允许装载计数器，上锁后出现偏差立即失锁。连续3个零偏差同步帧才上锁。
- CRC/帧长度/序列错误、超时均撤销锁定。4096周期收帧超时；独立晶振看门狗覆盖转发时钟完全停止的情况。
- 主板 S2/S3 经5ms去抖，分别预约共同清零/触发。常规预约提前1024周期；链路错误时不保证双方命令都已提交，本版本尚无双向确认事务。
- RTT 回传使用额外 SYNC_ECHO。默认148周期周转参数通过顶层行为仿真核对；实际板上需重新校准。单向延迟估计依赖链路对称假设，不能当作皮秒/纳秒级相位校准。

模块接口、计数时序见 `ARCHITECTURE.md`，接线表见 `PINOUT.md`。原始硬件说明作为输入材料归档；P4针数和时钟P/N端选择已经按原图及 Vivado 器件数据库修正，不直接沿用材料中的全部描述。

## 实板验收顺序

1. 确认两块 EBAZ4205、两个可用JTAG目标、供电与3.3V IO；先移除这些P5网络上的VGA等外设。
2. 根据PINOUT连接CLK、DATA、VALID、RESET、LOCK、ECHO和GND。P5/2是3.3V；两块板的示波器输出禁止互接。
3. 完成PS7/启动配置及实测IO时序复核后生成并下载对应bitstream；先观察锁定与帧传输，再验证复位/触发。
4. 示波器同时捕获两板P5/11触发及P5/13周期波形；记录偏斜、抖动、线长、探头与接地方式。
5. 断开/恢复同步时钟与数据，检验撤销锁定和重同步；实测连续运行超过1小时，保存原始数据后才能标记BOARD_TESTED/HARDWARE_VERIFIED。

下一阶段仍是TASK-001硬件收敛与验收；在时间基准实板验证之前，不进入相控阵或声学功能。
