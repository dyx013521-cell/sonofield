# EBAZ4205 + 教学扩展板硬件说明

> 本文档从 `01_原理图` 目录下的 PDF 原理图直接提取，用于补全/修正现有教程中的硬件描述。
> 覆盖范围：**核心板 `4205.pdf`**、**扩展板 `EBAZ4205_EXBOARD_20200313.pdf`**、**VGA/UART 模块 `vga_uart.pdf`**、**摄像头模块 `OPENSOC_OV5640_V1.0.pdf`**。

## 1. 核心板（4205.pdf）

### 1.1 器件型号

原理图标注：

```text
XC7Z010-1CLG400I
```

- `XC7Z010`：Zynq-7010 SoC。
- `-1`：速度等级 -1。
- `CLG400`：400 球 BGA 封装。
- `I`：工业级温度范围。

Vivado 2017.4 中新建工程应选择 **`xc7z010clg400-1`**（Vivado 的 Part 命名把速度等级放在末尾，温度等级默认省略）。

### 1.2 时钟（重点）

| 晶振 | 频率 | 状态 | 用途 |
| --- | --- | --- | --- |
| **X5** | **50.000 MHz** | **已焊，接入 N18** | PL 参考时钟 |
| X8 | 33.333 MHz | 未焊接（NC），仅留 J3 接口 | 公共资料常见值，但本板未用 |
| Y3 | 25.000 MHz | 已焊 | 以太网 PHY 时钟 |

![N18 50MHz 晶振](assets/core_clk_area.png)

> 长期以来教程把 `N18` 频率列为“待实测”，因为公共资料常写 33.333 MHz。核心板原理图明确：**X5 为 3.2×2.5 mm 50 MHz 有源晶振，直接接到 Zynq 引脚 N18**；33.333 MHz 的 X8 是 NC 空贴，只作为可选扩展接口。

因此：

- 纯 RTL 工程对 `N18` 的 `create_clock` 应使用 **`-period 20.000`**（50 MHz）。
- 不需要再对 `N18` 频率做“公共资料 vs 实测”的猜测。

### 1.3 JTAG

原理图中 JTAG 信号串接 22Ω 电阻后进入 Zynq：

| JTAG 信号 | Zynq 球 | 备注 |
| --- | --- | --- |
| TCK | F9 | 串联 22R |
| TDI | G6 | 串联 22R |
| TDO | F6 | 串联 22R |
| TMS | J6 | 串联 22R |

### 1.4 配置/状态引脚

| 信号 | Zynq 球 | 说明 |
| --- | --- | --- |
| PS_SRST_B | 专用 | PS 软复位 |
| PROGRAM_B_0 | 专用 | PL 配置复位 |
| CFGBVS_0 | 专用 | 配置 Bank 电压选择 |
| INIT_B_0 | 专用 | 配置初始化状态 |
| DONE_0 | 专用 | 配置完成 |

### 1.5 核心板 LED

| LED | Zynq 球 | 备注 |
| --- | --- | --- |
| 核心板 LED0 | W13 | 丝印旁通常标 D1/D2 |
| 核心板 LED1 | W14 |  |

> 极性未在本文中实测，使用前请先用静态图样验证。

### 1.6 电源

- 输入：**VCC_IN**（推荐先确认插座极性，常见为 5 V）。
- 核心板通过 **AMS1117-3.3**（U1）产生 **VCC_3V3**。
- 扩展板的 3.3 V、VCC_IN、GND 通过 P7/P1/P2/P3 供给。

> ⚠️ **上电前务必确认电源电压与极性**，反接可能直接损坏核心板。

## 2. 扩展板（EBAZ4205_EXBOARD_20200313.pdf）

> 版本：**EBAZ4205 转接板 V1.1**，日期 2020/3/13，来源 www.opensoc.cn（开源骚客）。

### 2.1 连接器概览

| 连接器 | 类型 | 主要用途 |
| --- | --- | --- |
| P1 / P2 / P3 | Header 10×2，2.0 mm | 与核心板 DATA 连接器对接 |
| P4 | Header 10×2 | 额外 GPIO/排针 |
| P5 | Header 14×2 | 额外 GPIO/排针 |
| P6 | Header 2 | UART（TXD/RXD） |
| P7 | Header 3×2 | 电源/接口 |

### 2.2 4 路按键（已确认）

![扩展板按键电路](assets/ex_keys.png)

| 按键丝印 | 网络名 | Zynq 引脚 | 空闲电平 | 按下电平 | 上拉电阻 | 串联电阻 |
| --- | --- | --- | --- | --- | --- | --- |
| S1 | KEY_1 | **G19** | 1 | 0 | R1 10K | R5 220R |
| S2 | KEY_2 | **J19** | 1 | 0 | R2 10K | R6 220R |
| S3 | KEY_3 | **K19** | 1 | 0 | R3 10K | R7 220R |
| S4 | KEY_4 | **L16** | 1 | 0 | R4 10K | R8 220R |

> 每个按键都有 10K 上拉到 VCC_3V3，按下时经 220R 接到 GND → **低电平有效**。这一结论与此前板上实测（G19 空闲 1/按下 0）一致。

### 2.3 4 路 LED（已确认）

![扩展板 LED 电路](assets/ex_leds.png)

| LED 标号 | 网络名 | Zynq 引脚 | 限流电阻 | 点亮方式 |
| --- | --- | --- | --- | --- |
| D1 | LED0 | **H20** | R9 2K | 低电平点亮 |
| D2 | LED1 | **K18** | R10 2K | 低电平点亮 |
| D3 | LED2 | **J20** | R11 2K | 低电平点亮 |
| D4 | LED3 | **L19** | R12 2K | 低电平点亮 |

> 想要“一亮三暗”请使用 **one-cold** 图样，例如 `4'b1110` 只让 `led[0]` 为 0。

### 2.4 VGA 接口

扩展板直接把 Zynq 引脚接到 VGA 排针，通过电阻网络 DAC 产生 RGB565 信号。

| 信号 | Zynq 引脚 | 说明 |
| --- | --- | --- |
| VGA_R4 | P20 | 与摄像头/其他功能冲突时按当前实验取舍 |
| VGA_R3 | M17 |  |
| VGA_R2 | N20 |  |
| VGA_R1 | M20 |  |
| VGA_R0 | M18 |  |
| VGA_G5 | L17 |  |
| VGA_G4 | L20 |  |
| VGA_G3 | U19 |  |
| VGA_G2 | T19 |  |
| VGA_G1 | T20 |  |
| VGA_G0 | R19 |  |
| VGA_B4 | P19 |  |
| VGA_B3 | R18 |  |
| VGA_B2 | N17 |  |
| VGA_B1 | P18 |  |
| VGA_B0 | M19 |  |
| VGA_HSYNC | U20 |  |
| VGA_VSYNC | V20 |  |

电阻网络参考值来自 `vga_uart.pdf`（同一批学习模块的 VGA 电路），典型为二进制加权电阻：

- R（5 位）：0.5K / 1K / 2K / 4K / 8K
- G（6 位）：0.5K / 1K / 2K / 4K / 8K / 16K
- B（5 位）：0.5K / 1K / 2K / 4K / 8K

> 扩展板实际电阻值以扩展板原理图/实物为准；`vga_uart.pdf` 仅作为同方案参考。

### 2.5 OV5640 摄像头接口

| 信号 | Zynq 引脚 | 说明 |
| --- | --- | --- |
| OV_D0 | B20 |  |
| OV_D1 | B19 |  |
| OV_D2 | C20 |  |
| OV_D3 | H17 |  |
| OV_D4 | D20 |  |
| OV_D5 | D18 |  |
| OV_D6 | H18 |  |
| OV_D7 | D19 |  |
| OV_PCLK | E19 | 非专用时钟引脚，需 `CLOCK_DEDICATED_ROUTE FALSE` |
| OV_HREF | F19 |  |
| OV_VSYNC | K17 |  |
| OV_XCLK | F20 | 摄像头主时钟（24 MHz） |
| OV_SCL | J18 | SCCB 时钟 |
| OV_SDA | G20 | SCCB 数据 |
| OV_RESET | A20 | 低有效 |
| OV_PWDN | H16 | 掉电控制 |

### 2.6 关键冲突与使用规则

1. **A20 复用**：摄像头实验用作 `ov5640_rst_n`；旧 VGA 图片加载实验用作 PL UART RX。同一时刻只能二选一。
2. **P20 复用**：VGA_R4 与扩展板其他功能/核心板信号复用，做纯 VGA 实验时把它当 VGA 用即可。
3. **XDC 文件不要混用**：当前顶层没有使用的端口要注释或删除，否则 `get_ports` 会报“找不到对象”。
4. **VCC_IN 极性**：扩展板 P7/P1/P2/P3 上把 VCC_IN 和 GND 成对引出，接线前务必核对。

## 4. 与现有文档的差异/修正

| 项 | 旧描述 | 本次原理图确认 |
| --- | --- | --- |
| `N18` 频率 | 旧工程按 50 MHz，公共资料常见 33.333 MHz，待实测 | **X5 已焊 50 MHz，33.333 MHz 空贴**，`N18` 确定是 50 MHz |
| 扩展板按键 | 文档只确认 G19 | **4 个按键：G19/J19/K19/L16**，全部带 10K 上拉 |
| LED 限流电阻 | 未注明 | **2K**，低电平点亮 |
| 按键串联电阻 | 未注明 | **220R** |
| 核心板型号 | `xc7z010clg400-1` | 原理图标 `XC7Z010-1CLG400I`，Vivado Part 仍用 `xc7z010clg400-1` |
| JTAG 引脚 | 仅说“外接 Xilinx 下载器” | TCK=F9, TDI=G6, TDO=F6, TMS=J6，均串 22R |

## 5. 仍建议上板前确认的事项

以下项目即使原理图给出，也建议首次使用前用万用表/示波器再核对一次：

- 电源入口电压、极性、最大电流。
- 核心板 W13/W14 两颗 LED 的极性。
- JTAG 排针（核心板或扩展板上的 JTAG 插座）的引脚顺序是否与下载器线序一致。
- 扩展板 P5/P6/P7 的物理针脚定义（如 UART TX/RX 方向）。
- 不同批次扩展板的按键/LED 是否沿用同一引脚（目前证据仅来自这批 V1.1 转接板）。
